# Library-Management-System-
A full-stack Library Management System built with Java, SQLite, JDBC, HTML, CSS, and JavaScript. The system provides a clean web-based interface for managing books, members, users, and library transactions. 
Features
🔐 User login and account registration
📚 Add, update, delete, search, and manage books
👥 Manage library members
📖 Issue and return books
📅 Automatic due-date tracking
💰 Automatic fine calculation for overdue books
📊 Track book availability and active transactions
🗄️ SQLite database with automatic schema initialization
🌐 Java-based API server with web frontend
🔒 Password hashing and user authentication
Tech Stack

Backend: Java, JDBC, HTTP API
Database: SQLite
Frontend: HTML, CSS, JavaScript
Database Driver: SQLite JDBC

This project demonstrates database management, CRUD operations, REST-style API handling, transaction management, authentication, and integration between a Java backend and web frontend.
